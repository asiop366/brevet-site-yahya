# Brevet 2026 — Révisions

Application de révision pour le brevet des collèges (session AEFE Maroc, 18 juin 2026).

- **Web / PWA** : [brevet-site-yahya.vercel.app](https://brevet-site-yahya.vercel.app)
- **iPhone** : voir [INSTALL-IOS.md](INSTALL-IOS.md)

## Fonctionnalités

- Quiz aléatoire par matière (maths, français, histoire-géo, EMC, sciences)
- Compte à rebours, score, série, planning
- Fonctionne hors-ligne (PWA)

## Développement

```bash
npm install
npm run build:web
```

Le site est servi depuis le dossier `www/`.
